# Inquiry Workspace：剩余实施与验收清单

本清单记录当前工作树中仍需实施或验证的工作。现有新模块默认关闭，旧系统仍独立运行；自动化使用的固定模型不能证明真实模型规划能力。

## P0：安全与恢复

- [ ] 设计失败或取消运行成果的显式隔离及重新审核：当前版本保留全部生成运行约束，可能使教师修正后的对象一直无法导出。不得直接清除来源或把失败运行改为成功；需保留历史和撤权约束，提供可审核的新版本或不参与报告的安全处置，并测试历史快照。
- [ ] 区分风险批准和补充信息后重新规划：缺失信息目前不能靠批准完成，待审核运行可取消；仍需实现填写补充信息、重新规划、保留教师修改和重新执行验证的完整流程，覆盖工作空间在审核中变化的情况。
- [ ] 超时处理目前能阻止迟到结果提交，且同进程设置了节点并发上限；Python 线程不能强制终止。需要可终止或有界的执行隔离，检索审计提交前核验当前租约和授权，并覆盖取消、进程退出及重复超时。
- [ ] 增加旧 worker 租约过期后与新 worker 竞争提交、模型运行中撤销教师角色、撤销课标授权同时读取历史版本/事件/快照等竞争测试。
- [ ] 按真实历史数据结构扩展迁移测试，覆盖未知结构、重复父对象、已有活动运行和重复启动，验证失败后用户数据保持不变。

## P1：编排与教师体验

- [ ] 为每项原子能力定义独立输入、输出和教学对象 Schema，限制所有受支持字段、错误类型、重试与副作用；增强 Planner 能力说明和输入绑定。
- [ ] 在 Agent 产生依赖时记录实际消费的字段；缺少可信字段信息时继续按整对象保守传播。验证多级重编排使用最新上游输出，并覆盖锁定、教师编辑及待审边界。
- [ ] 进一步验证中断、worker 重启、租约回收和取消重试；将事件流接入前端，提供按序号断线续传及网络错误恢复。目前页面主要轮询运行状态。
- [ ] 完成教学对象添加、删除、排序、版本比较与恢复界面，完善字段编辑、409 合并、状态、课程依据及依赖显示。
- [ ] 完善报告章节和待确认事项，提供失败生成内容的安全隔离；以并发编辑、Word 与打印视图一致性及撤权为重点补充验收。
- [ ] 扩展实验交互测试，覆盖无障碍、失败重试、未保存输入保护、并发冲突、刷新恢复与显式选择报告记录。
- [ ] 对比完整教学设计、独立实验和局部修改三类任务的真实计划、执行节点及对象版本，验证不是硬编码模板。

## P2：V1 图谱与协作

- [ ] 通过只读适配器接入现有知识图谱及明确存在的关系，校验权限；不将生态关系推断为课程前置关系。
- [ ] 建立知识节点与教学对象的关联，支持从节点查看对象或请求生成活动；图谱、对象依赖图和执行 DAG 分别维护。
- [ ] 完善智能协作确认及自由创作，确保各种入口共享 Artifact、权限和 Runtime。

## 最终验收

- [ ] 在全部更改后重跑新模块、前端单元、浏览器 E2E、构建和旧系统回归，覆盖开关关闭、开启及新运行失败。
- [ ] 使用真实配置模型抽样三类任务、授权课标引用和教学安全；记录环境限制和脱敏结果。
- [ ] 再次独立审查权限撤销、快照、运行来源、租约竞争、审核恢复和错误完成状态。

学生执行与学习反馈仍属于 V2。不要修改旧主导师、专家、阶段流程、草案、会话、知识库或图谱的原有行为。
